# Магазин вратарской экипировки

Учебный проект по веб-программированию. Тематикой взят магазин экипировки для хоккейных вратарей.
Фотографии только для демонстрации, заказ оформить будет нельзя.

Задание: https://github.com/Dasha2101/WEB2025Q26

## Что сделано

- Основа страницы: шапка, навигация, каталог, описание проекта и подвал.
- Четыре карточки товаров с фотографией, названием, описанием и ценой.
- Данные товаров в отдельном файле `scripts/data.js`.
- Создание карточек через `createElement` и `textContent`.
- Базовое оформление на CSS Grid и Flexbox.
- Локальные PNG-фотографии и SVG favicon в папке `images`.
- Адаптивная верстка: четыре колонки на широком экране, две на планшете и одна на телефоне.
- Корзина: добавление, удаление и изменение количества товара.
- Автоматический пересчёт итоговой суммы и количества товаров в шапке.
- Проверка на некорректные числа при вводе корзины.

Сохранение и оформление заказа - yet to be implemented...
